# Memory Decay

Memory Decay is a static, spaced-repetition study interface built with
vanilla JavaScript and Tailwind CSS. It has no backend and does not currently
persist or schedule reviews.

## Current implementation

This repository contains the production-style static UI for the Memory Decay
dashboard and its primary screens. The interface uses sample data and real
navigation links, but no local-storage or recall engine logic.

The dashboard follows the approved prototype layout:

- Full-width application shell with no page margin
- Fixed-height header
- Left sidebar on desktop
- Top navigation row on mobile
- Independently scrolling main content
- Upcoming Due, Status, and Average retention cards
- Shared color, typography, spacing, border, and badge styles

## Structure

```text
index.html                 Dashboard entry point
input.css                  Tailwind source stylesheet
app.css                    Compiled Tailwind output
tailwind.config.js         Theme and content scanning
src/
  scripts/
    components.js         Shared header, sidebar, and floating add button
  pages/                   Static application pages
references/                Gitignored read-only prototype
```

## Shared shell

[components.js](/Users/ntggamer1/Desktop/NTgGamer1/Hackathons/Memory-Decay/src/scripts/components.js)
injects the shared header and sidebar into every page. Each page declares its
active navigation state through `data-active` on `<body>`. Header links and
sidebar links use relative paths that resolve from both the root dashboard and
pages below `src/pages`.

## Styling

- Edit [input.css](/Users/ntggamer1/Desktop/NTgGamer1/Hackathons/Memory-Decay/input.css)
  for Tailwind source and shared component styles.
- Do not edit [app.css](/Users/ntggamer1/Desktop/NTgGamer1/Hackathons/Memory-Decay/app.css)
  by hand. It is generated by Tailwind.
- [tailwind.config.js](/Users/ntggamer1/Desktop/NTgGamer1/Hackathons/Memory-Decay/tailwind.config.js)
  scans `index.html` and `src/**/*.{html,js}`.

The theme uses a paper/ink palette, sage accents, Georgia display typography,
and the prototype card, badge, and navigation visual language.

## Development

Install dependencies:

```bash
npm install
```

Build the stylesheet once:

```bash
npm run build
```

Watch Tailwind source files while developing:

```bash
npm run dev
```

Run the build verification:

```bash
npm test
```

## Reference prototype

`references/` contains the older working prototype and is intentionally
gitignored. It is read-only reference material. Do not copy its markup or
implementation into production, and never commit files from it.

The approved dashboard screenshot is the visual target. Production changes
should preserve card spacing and styles while retaining the full-screen shell:
no outer page margin, no centered max-width, no rounded outer corners, and no
outer page border, shadow, or gradient.
