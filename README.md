# Memory Decay

Memory Decay is a fully client-side spaced-repetition application built with
vanilla JavaScript, Tailwind CSS 3.4, and PostCSS. There is no backend.
Application data is stored in the user's browser.

## Current status

The approved full-screen interface is implemented for the Dashboard, Concepts,
Concept detail, Recall test, Recall result, and Settings views.

The UI currently uses real empty states. Data persistence and the recall engine
are being added in the next implementation phases.

## Structure

```text
index.html
input.css
app.css
tailwind.config.js
javascripts/
  main.js
  logic.js
src/pages/
  concept.html
  concepts.html
  recall.html
  result.html
  settings.html
references/
```

## Styling

- Edit `input.css` for Tailwind source and shared component styles.
- Never edit `app.css` by hand; it is generated by Tailwind.
- `javascripts/main.js` owns UI behavior and DOM rendering.
- `javascripts/logic.js` owns engine and storage logic only.
- `references/` is read-only and gitignored.

## Development

```bash
npm install
npm run build
npm run dev
npm test
```

`npm run build` creates the CSS stylesheet once. `npm run dev` watches
Tailwind source files.
